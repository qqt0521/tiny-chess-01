A compact original chess engine in under 4 KB of Python: 0x88 board, negamax with alpha-beta, quiescence search, transposition table, killer moves and a fixed node budget. No clock, no randomness, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
